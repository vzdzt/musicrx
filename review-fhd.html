2014 FOREST HILLS DRIVE

System Status

J. Cole’s 2014 Forest Hills Drive activated December 9, 2014 via Roc Nation, Columbia, and Dreamville. This 13-track, 64-minute core system logged 353,000 units first week, securing the Billboard 200. By March 25, 2025, it’s 3x Platinum (RIAA) with 4.8 billion Spotify streams. Calibrated with Vinylz, it’s a soulful reboot—Veazy marks it a red-hot classic still operational in 2025.
