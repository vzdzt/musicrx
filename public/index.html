🎵 MusicRx Backend API

This is the backend API for MusicRx media tools.

Available Endpoints:

POST /api/convert-video

Convert video URLs to MP3 audio

curl -X POST /api/convert-video -H "Content-Type: application/json" -d '{"url": "https://youtube.com/watch?v=..."}'

POST /api/download-media

Download media from social media posts

curl -X POST /api/download-media -H "Content-Type: application/json" -d '{"url": "https://instagram.com/p/..."}'

GET /api/health

Health check endpoint

curl /api/health
